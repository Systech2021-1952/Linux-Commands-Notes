# Basic Commands in Linux


### 1. Present working directory:
ubuntu@root:~$ pwd
> /home/ubuntu

## 2. Version:
ubuntu@root:~$ uname -а
> version will appear

## 3. Username:
ubuntu@root:~$ whoami 
> ubuntu

## 4. Clearing the screen:
ubuntu@root:~$ clear          (ctrl + l)
> Terminal will be cleared.

## 5. Viewing command history:
ubuntu@root:~$ history
> Total history can be viewed.
