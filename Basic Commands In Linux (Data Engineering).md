# Basic Commands in Linux


### 1. Present working directory:
ubuntu@root:~$ pwd

&rarr; /home/ubuntu


## 2. Version:
ubuntu@root:~$ uname -а

&rarr; version will appear


## 3. Username:
ubuntu@root:~$ whoami 
> ubuntu

## 4. Clearing the screen:
ubuntu@root:~$ clear          (ctrl + l)
> Terminal will be cleared.
