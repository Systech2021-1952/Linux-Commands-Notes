# Basic Commands in Linux (Data Engineering)

**1. Present working directory:**
```bash
ubuntu@dheen:~$ pwd
/home/ubuntu
```
**2. Version:**
```bash
ubuntu@dheen:~$ uname -a
# version will appear
```
**3. Username:**
```bash
ubuntu@dheen:~$ whoami
ubuntu
```
**4. Clearing the screen:**
```bash
ubuntu@dheen:~$ clear
# Terminal will be cleared (Shortcut: Ctrl + L)
```
