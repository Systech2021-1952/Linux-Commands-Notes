# Basic Commands In Linux
(1) Present working directory:

ubuntu@dheen:~\$ pwd

= /home/upuntu

Version:

ubuntu@dheen:~\$ uname -a

= version will appear

- Username:

ubuntu@dheen:~\$ whoami

= uopuntu

- (4) Clearing the screen:

ubuntu@dheen:~\$ clear

(ctrl +L)

= Terminal will be cleared.

(5) Viewing command history:

ubuntu@dheen:~\$ history

= Total history can be viewed.
